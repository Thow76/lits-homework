# Drop folder for the Shopping unit content

Andrew: put the raw material for the Shopping unit in this folder. The content task reads everything here and builds `units/shopping/unit.json` from it. Nothing in this folder is shown to learners.

## How to upload files here without any software
1. Open https://github.com/Thow76/lits-homework/tree/main/content/shopping
2. Click **Add file** (top right) → **Upload files**.
3. Drag your files in, write anything in the box at the bottom (for example "Shopping content"), click **Commit changes**.

## What to put here
- **worksheet** — the class worksheet: `worksheet.docx`, `worksheet.pdf` or `worksheet.txt`. It should contain the story, the vocabulary list and the dialogue. If the worksheet already groups exercises under the five section headings, the task will follow them.
- **notes.txt** (optional) — anything the worksheet does not say: which games you want in which section, release dates, new section names, words to leave out.
- **pictures** — one image per vocabulary word, named after the word: `bread.jpg`, `milk.png`, `shop.jpg`. Any size; the task shrinks them.
- **audio** — one recording per sentence or word. Name each file with the words it says, for example `I-go-to-the-shop.m4a` or `bread.mp3`, or add a file `audio.txt` with one line per file: `filename = the sentence it says`. Any format; the task converts to small mono MP3.
- **dates.txt** (optional) — one line per section: `Vocabulary and first practice = 2026-11-03`. Dates are the day the section opens for learners (UK time). Leave this out and the task will ask you for the dates in its notification.
